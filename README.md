# ST WI Folder

SillyTavern 월드인포(로어북) 파일을 폴더로 묶어서 목록을 줄이는 확장입니다.

캐릭터나 채팅에 자동으로 연결된 로어북, 백업용 로어북처럼 직접 고를 일이 없는 책을 폴더에 넣고 접어 두면, 편집 드롭다운과 "Active World(s)" 목록에서 사라집니다. 로어북 자체는 그대로이므로 캐릭터·채팅 연결은 계속 동작합니다.

## 설치

SillyTavern → 확장(Extensions) → Install extension 에 이 저장소 주소를 넣습니다.

## 사용법

1. 월드인포 서랍 맨 위 "로어북 폴더" 줄에서 **새 폴더**를 누릅니다.
2. 편집 드롭다운(Pick to Edit)에서 책을 고르면 옆에 폴더 선택이 켜집니다. 폴더를 고르면 책이 그 폴더로 들어갑니다.
3. 폴더 아이콘을 누르면 접힙니다. 접힌 폴더의 책은 두 목록에서 숨겨집니다. 다시 누르면 보입니다.
4. 연필은 이름 변경, 휴지통은 폴더 삭제입니다. 폴더를 지워도 로어북은 지워지지 않습니다.

전역 활성 상태이거나 편집 중인 책은 접힌 폴더에 있어도 계속 보입니다.

## 알아둘 점

- 폴더 정보는 SillyTavern 설정(`extension_settings.st_lorefolders`)에 저장됩니다. 로어북 파일은 바꾸지 않습니다.
- 로어북 이름을 바꾸면 폴더에서 빠집니다. 다시 넣어 주세요.
- 동작 방식: SillyTavern의 select 요소는 그대로 두고 option만 `hidden`/`disabled`로 표시한 뒤, select2 드롭다운에서 CSS로 숨깁니다.
